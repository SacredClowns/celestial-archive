## 1. Preferred Terms Table

| Term | Preferred Form | Notes |
|------|---------------|-------|

| Liber Loagaeth | *Liber Loagaeth* (italicized) | Full form on first use per lesson. "Loagaeth" acceptable for subsequent references within the same section. |
| Watchtower Tablet | Watchtower Tablet (both capitalized) | Never "watchtower tablet" or "Watch Tower." |
| Tablet of Union | Tablet of Union (capitalized) | Never "tablet of union." |

| Heptarchia Mystica | *Heptarchia Mystica* (italicized) | "Heptarchia" alone acceptable after first italicized use within the same section. |

| single-witness (adj.) | Hyphenated when adjectival: "single-witness problem" | Unhyphenated as noun phrase: "single witness." |
| reconstruction | Use for what the Golden Dawn did | "restoration" only within ○-badged claims quoting the GD's own framing. |
| parallel | Use only when badged ◎ | Use "comparison," "resemblance," or "correspondence" when unbadged. |
| opacity | "Resistance to interpretation" | Not "obscurity" or "incomprehensibility." |

## 2. Terms to Avoid in Lesson Prose

| Avoid | Use Instead | Exception |
|-------|------------|-----------|
| prove / proof | "establishes," "documents," "shows," "indicates," "evidence" | Acceptable inside quoted material or when describing what *others* claim to do. |
| certain / certainty (as verdicts) | "confident," "well-supported," "strongly indicated" | Acceptable in reflection prompts describing hypotheticals, or when describing a cognitive state ("felt certain"). |
| Enochian language (as if Dee's term) | Angelic Language (Dee's term); Enochian (later name) | "Enochian" is fine as a standalone adjective for the system broadly. |
| action diaries | session diaries | Unless directly quoting Whitby's terminology. |
| MSS (in lesson prose) | manuscripts | Acceptable in source packs and citations. |
| obscurity / incomprehensibility | opacity | When describing resistance to interpretation. |
| restoration (for GD work) | reconstruction | Unless within ○-badged claims attributing the GD's own framing. |

## 5. Consistency Verdict

**Does the rank now read as one voice?**

Yes. After normalization, the six Student lessons present a unified terminological surface. The key improvements:

- **Watchtower Tablet/Tablets** is now consistently capitalized across all six lessons. The prior drift (lowercase "tablets" in Lessons 1 and 5) has been corrected.
- **"proof/prove"** has been removed from lesson prose where it appeared as the Archive's own language. The Archive now consistently uses "evidence," "establishes," "shows," "indicates," and "demonstrates." The word "proof" survives only in (a) the ○-badged Traditional Occult Lens ("Its elegance is itself a kind of proof" — a practitioner claim), (b) a wrong answer option in a knowledge check, and (c) the Lesson 6 closing recap which has been aligned to "evidence."
- **Angelic Language vs. Enochian** is now consistently applied: "Angelic Language" when describing what Dee and Kelley called it; "Enochian" when describing the later name and the system broadly.
- **Work titles** (*Heptarchia Mystica*, *Liber Loagaeth*) are now italicized on first use in each lesson where they appear.
- **"session diaries"** is now the consistent term for the manuscript objects. The single occurrence of "action diaries" (in a Whitby citation description) has been normalized.

**Terms that required no edits:**
- "Great Table" — already consistently capitalized across all lessons.
- "Tablet of Union" — already consistently capitalized.
- "Reformed Table" / "Reformed Great Table" — already consistently capitalized; no instances of "Revised Table" found.
- "single-witness" / "single witness" — already correctly hyphenated as adjective, unhyphenated as noun.
- "reconstruction" vs. "restoration" — "restoration" appears only within ○-badged claims attributing the Golden Dawn's own language, which is correct.
- "opacity" — used consistently; no instances of "obscurity" or "incomprehensibility."
- "MSS" — does not appear in any lesson prose.
- "certainty/certain" — all uses are contextually appropriate (describing cognitive states in reflection prompts, or describing what to avoid).

The rank reads as one voice. The terminological surface is clean. The primary remaining editorial concern is not terminological but structural: the Peterson 2003 verification for Heptarchic king/prince names in Lesson 2.1 remains outstanding, as flagged in that lesson's status line.
