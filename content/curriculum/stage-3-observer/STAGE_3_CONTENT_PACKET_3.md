## Central Theme

The Student learned the Great Table as **geometry and witness comparison**. The Observer watches the same structure **being used** across traditions — without equating use with authenticity or dismissing use as corruption.

**Signature question:** *What changes when a manuscript grid becomes a ritual instrument — and whose grid is it?*

## Learning Goals

1. Compare two+ traditions' Watchtower workings (Golden Dawn, Thelemic line, independent modern) — what each adds/removes (**△** vs **◆**).
2. Articulate the gap between Dee-era manuscript description and any living practice.
3. Apply Source Discernment to ritual instructions (author, date, chain, authority).
4. Separate studying structure from observing practice — epistemic consequences named.

## Structural Outline

### Opening
Split screen concept (prose): same letters on a page · same letters in a temple. Neither image cancels the other.

### Core I — Dee's Table as Record
Sloane 3191 / Cotton material — extraction rules, version differences (**◆**). No re-teach of full grid math — cue Student 2.4.

### Core II — Golden Dawn in Motion
Mathers rearrangement, Tablet of Union as separate object, color/Kabbalistic overlays (**◆** integration fact; **△** overlays). Primary: Regardie, GD papers — reception history.

### Core III — Modern Working Traditions (plural)
Present at least two non-GD lineages fairly (e.g. independent Enochian practitioners, published ritual manuals post-1970s). **○** for claimed results; **◇** for documented existence of practices.

### Core IV — The Gap Table
| Layer | What it is | Badge |
|-------|------------|-------|
| Manuscript grid | Dee/Kelley record | ◆ |
| Critical edition | Peterson, etc. | ◆/◇ |
| GD reconstruction | Operative synthesis | △ |
| Contemporary solo work | Living tradition | ○/△ |

### Lens Sections
Historical · Occult (multiple voices) · Psychological (ritual as attention technology) · Symbolic (fourfold structure — **◎** only if criteria met)

### Discernment Box
Source Discernment applied to a sample ritual instruction paragraph — trace who published it and when.

### Reflection · Knowledge Check · Closing
Close with equilibrium: structure is real in manuscripts; use is real in communities; neither is the whole.
