## XIII. NAVIGATION PRINCIPLES

1. **Three-Click Rule**: Any content reachable within 3 taps from home
2. **Cross-Linking**: Every entity page links to related entities across all pillars
3. **Breadcrumb Trail**: User always sees where they are in the hierarchy
4. **The Compass**: Persistent mini-map widget for spatial orientation
5. **Source Badge**: Every page shows which tradition(s) inform it
6. **Progressive Reveal**: Locked content shows a shimmer/glow rather than being invisible — the user knows something is there
